AI Chat Assistant Bot

Overview
Instant AI powered conversations across Telegram groups with customizable prompts.

Features
- Answer questions with AI models
- Support multiple models
- Customizable system prompts
- Persistent storage with SQLite

Local Setup
1. Clone the repository.
2. Create a virtual environment and activate it.
3. Install dependencies using pip install -r requirements.txt
4. Copy .env.example to .env and add your bot token.
5. Run python main.py

Deployment Guide
Deploy easily on Render or Koyeb using a background worker service running Python 3.11.
